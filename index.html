      What is GitView?

      GitView is a GitHub profile exploration tool that queries the public GitHub REST API to retrieve and visualize developer information — profiles, repositories, languages and activity — entirely in your browser.

      Technologies

      • HTML5
      • CSS3
      • JavaScript (ES6+)
      • JSON
      • REST API
      • Fetch API
      • LocalStorage

      Data source

      All data is fetched live from the GitHub REST API. Nothing is stored on a server — favorites, history and theme live in your browser's local storage only.
